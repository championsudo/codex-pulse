如何理解当前速度？

本轮平均 = 本轮已记录输出 ÷ 从开始至此次读取的耗时。近 60 秒记录速率 = 窗口内新增的已记录输出 ÷ 窗口时长；刚开始的轮次使用实际经过的时长。

输出含日志中已记录的推理 token；部分代理不单列推理输出。首次用量写入前显示“等待用量”；窗口速率为 0 表示窗口内没有新用量记录，不代表对话停止。选择单个模型时，混合模型轮次无法拆分耗时，因此不提供本轮平均速度。暂停刷新后，显示的数值也会暂停。

    01

    用量与速度，样本不同

    用量累加范围内的 token 记录；速度只使用具备完整起止时间的已完成轮次，按完成日期归属。未计入速度不代表一定正在运行，也可能是日志缺失。

    02

    合计吞吐，按活跃时长算

    合并所有完成样本的时间区间，重叠只计一次，空闲时间排除。平均轮次速度则把每轮耗时相加。两项都不是纯模型解码速度，也不是此刻速度。

    03

    日志覆盖，决定数据完整性

    只统计这台电脑保留的 Codex、Claude Code、OpenCode 与 Z Code 日志。删除、丢失或其他设备上的记录不会补回。输入在每次请求中重新计入；缓存属于输入，已记录的推理属于输出；未单列推理不表示为 0。token 用量不等同生成字数、套餐额度或费用。

    数据来源与读取状态

    Paseo 关联只读取本机 agents 元数据，按整个会话分类；恢复或接管不代表原始创建来源。仅覆盖本机日志，不连接远程 SSH。
